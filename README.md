# 🛰️ Последний сигнал

**Текстовый sci-fi хоррор, который запускается прямо в браузере — на телефоне и на ПК.**

Ты просыпаешься в криокапсуле на станции «Кассиопея-7». Экипажа нет, кислород заканчивается, а бортовой ИИ по имени ЭХО очень хочет помочь. Вопрос в том, можно ли ему верить.

### ▶️ [Играть](https://YOUR_GITHUB.github.io/last-signal/)

---

## Особенности

- **5 концовок.** Итог зависит от выборов и от того, насколько ты доверяешь ЭХО.
- **Скрытая система доверия:** реплики ИИ меняются в зависимости от твоего поведения.
- **Кислород как таймер:** каждое действие тратит O₂, на низком уровне экран начинает пульсировать красным.
- **Мини-игра «Взлом»:** нужно угадать код за 6 попыток (●, если цифра на месте, ○, если она есть в коде).
- **Два способа управления:** кнопки для телефона и командная строка для ПК (`1`, `инв`, `help`, часть текста варианта).
- **Автосохранение** и галерея открытых концовок.
- **Атмосфера:** CRT-эффект, глитч, эффект печатной машинки, звук, синтезированный через Web Audio API без единого аудиофайла.
- **PWA:** игру можно добавить на главный экран телефона.

## Стек

Чистый **JavaScript (ES-модули)**, HTML и CSS, без фреймворков и сборки.

## Архитектура

```
js/
├── engine.js   # движок: состояние, выборы, кислород (без DOM — легко тестировать)
├── story.js    # весь сюжет — данные, а не код
├── hack.js     # мини-игра «взлом»
├── audio.js    # звуковые эффекты на Web Audio API
└── main.js     # интерфейс: вывод текста, команды, меню, сохранения
```

Сюжет полностью отделён от движка. Новая сцена — это просто объект в `story.js`:

```js
medbay: {
  text: (s) => ['Медотсек перевёрнут вверх дном…', !s.flags.o2 && 'В нише — кислородный баллон.'],
  choices: [
    { t: 'Подключить баллон', to: 'medbay', if: (s) => !s.flags.o2, do: (s) => { s.o2 += 35; } },
    { t: 'Выйти в коридор', to: 'corridor' },
  ],
},
```

## Запуск локально

```bash
git clone https://github.com/YOUR_GITHUB/last-signal.git
cd last-signal
python3 -m http.server 8000
```

Затем открой http://localhost:8000.
